# CV-ready project description

Built an end-to-end **Enterprise Master Data & Data Quality Management System** for a simulated pharmaceutical company using Python, Pandas, SQL and PostgreSQL-ready schemas. Designed reproducible CRM, ERP and sales source feeds; implemented automated data-quality checks for completeness, validity, uniqueness, consistency and referential integrity; standardized customer and product data; and created confidence-scored source-to-master mappings with lineage and review controls. Produced governed master tables, KPI-ready analytics outputs and Power BI dashboard specifications.

Interview framing: “I treated raw source data as immutable, measured quality before remediation, then created governed canonical records without deleting provenance. Exact contact data drove high-confidence matches; fuzzy similarity was deliberately routed to review unless supported by stronger evidence.”
